# tohelper 实现修改方案 v2

## 设计原则

1. **零侵入 DSH 工程**：不修改 `deepseek-harness` 任何源文件，仅通过 `--patch` 机制加载
2. **模块化**：分为 tool、mcp、skill 三个独立模块
3. **Host 层运行**：通过监听 `agent/created` 事件获取 agent scope，无需嵌入 preset

## 核心发现：Host 层可以操作 Agent Scope

之前认为必须作为 preset 行才能访问 agent scope 的工具。实际上有更好的方式：

```
Host 层插件  ──监听──→  agent/created 事件
                              │
                              ▼
                        获取 agent 对象
                              │
                    ┌─────────┼─────────┐
                    ▼         ▼         ▼
            agent.ctx    agent.session   agent.id
            (scoped)     (session data)
                    │
         ┌──────────┼──────────┐
         ▼          ▼          ▼
  ctx.tools      ctx.tools    ctx.skills
  .schemas(agent)  .restrict() .list({scope:agent})
  (读取agent视图)  (通过agent.ctx) (agent层skills)
```

**关键 API**：
- `ctx.agents.list()` — 获取所有活跃 agent
- `ctx.on('agent/created', ({ agent }) => ...)` — 监听 agent 创建
- `ctx.tools.schemas(agent)` — 获取指定 agent scope 内的工具列表
- `agent.ctx.tools.restrict({ deny })` — 对特定 agent 应用工具限制
- `ctx.skills.list({ scope: agent, cwd })` — 获取指定 agent 的 skill 列表

这意味着插件可以完全在 Host 层运行，不需要修改任何 DSH 文件。

## 三模块架构

```
src/
├── index.ts            # 入口：插件声明、agent 追踪、前端注入
├── modules/
│   ├── tool.ts         # Tool 模块：内置工具发现与展示
│   ├── mcp.ts          # MCP 模块：MCP 服务器管理与工具启停
│   └── skill.ts        # Skill 模块：技能目录浏览
├── api.ts              # HTTP 路由注册（聚合三模块的 endpoint）
├── widget.ts           # 前端 JS/CSS 字符串（悬浮组件）
└── types.ts            # 共享类型定义
```

### 模块职责

| 模块 | 职责 | 数据来源 | 用户操作 |
|------|------|----------|----------|
| **tool** | 展示 agent 当前所有可用工具 | `ctx.tools.schemas(agent)` | 只读浏览 |
| **mcp** | 管理 MCP 服务器，启停 MCP 工具 | `ctx.plugin()` 动态加载 + `restrict` | 添加/移除 server，deny/allow 工具 |
| **skill** | 展示当前 agent 可用的技能目录 | `ctx.skills.list({scope: agent})` | 只读浏览（技能由模型按需加载） |

## 模块详细设计

### 1. Tool 模块 (`src/modules/tool.ts`)

**功能**：读取 agent scope 内注册的全部工具并分类展示。

```typescript
interface ToolModule {
  // 获取 agent 可见的全部工具（分为 builtin 和 mcp 两类）
  listTools(agent: Agent): { builtin: ToolInfo[]; mcp: ToolInfo[] }
}
```

**分类规则**：
- `name.startsWith('mcp__')` → MCP 工具
- 其余 → 内置工具

**实现要点**：
- 调用 `ctx.tools.schemas(agent)` 获取 agent scope 视图
- schemas() 返回的是该 agent 当前可见的工具（已经过 preset 组合和 restrict 过滤）
- 监听 `tools/change` 事件刷新缓存

### 2. MCP 模块 (`src/modules/mcp.ts`)

**功能**：动态管理 MCP 服务器连接、对 MCP 工具执行 restrict。

```typescript
interface McpModule {
  // 动态添加 MCP 服务器
  addServer(config: McpServerConfig): Promise<void>
  // 移除动态添加的 MCP 服务器
  removeServer(serverName: string): void
  // 列出动态添加的服务器
  listServers(): McpServerInfo[]
  // 禁用/启用特定 MCP 工具
  denyTools(agent: Agent, names: string[]): void
  // 恢复全部 MCP 工具
  resetDeny(agent: Agent): void
  // 获取当前被 deny 的工具名
  getDenied(): string[]
}
```

**实现要点**：

1. **动态添加 MCP Server**：
   ```typescript
   // 通过 ctx.plugin() 动态加载 mcp-client 实例
   const mcpClientModule = await import('@deepseek-ai/dsh-mcp-client')
   const fiber = ctx.plugin(mcpClientModule, {
     serverName: 'user-server',
     transport: 'stdio',
     command: 'npx',
     args: ['-y', '@modelcontextprotocol/server-xxx'],
     cwd: process.cwd(),
     toolCallTimeoutMs: 60000,
     failOnStartupError: false,
   })
   // fiber.dispose() 可移除该服务器
   ```

2. **工具启停**（通过 agent scope restrict）：
   ```typescript
   // 通过 agent.ctx 访问 scoped tools service
   const disposer = agent.ctx.tools.restrict({ deny: ['mcp__server__tool1'] })
   // 保存 disposer 以便后续恢复
   ```

3. **注意**：`restrict({ deny })` 要求 deny 列表中的工具名必须存在于当前 agent 的 restrictable 集合中，否则抛出错误。所以需要先过滤：
   ```typescript
   const allMcp = ctx.tools.schemas(agent)
     .filter(t => t.name.startsWith('mcp__'))
     .map(t => t.name)
   const validDeny = desiredDeny.filter(n => allMcp.includes(n))
   ```

### 3. Skill 模块 (`src/modules/skill.ts`)

**功能**：展示当前 agent 可见的技能目录。

```typescript
interface SkillModule {
  // 列出 agent 可见的全部 skill
  listSkills(agent: Agent): Promise<SkillInfo[]>
}
```

**实现要点**：
- 调用 `ctx.skills.list({ scope: agent, cwd: agent.session.header.cwd })`
- 返回 `SkillSummary[]`（包含 name, description, whenToUse, invocation policy）
- Skill 本身不需要"装卸"——模型通过 `skill` tool 按需加载
- UI 只展示目录，帮助用户了解当前 agent 有哪些可用技能

## 入口与生命周期 (`src/index.ts`)

```typescript
import type { Context } from '@deepseek-ai/cordis'
import type { Agent } from '@deepseek-ai/dsh-agent'

export const name = 'tohelper'
export const inject = ['webServer', 'tools', 'agents', 'skills'] as const

export function apply(ctx: Context): void {
  // 追踪活跃的 agent（web 模式通常只有一个）
  let currentAgent: Agent | undefined

  ctx.on('agent/created', ({ agent }) => {
    currentAgent = agent
  })
  ctx.on('agent/disposed', ({ agent }) => {
    if (currentAgent === agent) currentAgent = undefined
  })

  // 提供 getCurrentAgent() 给各模块使用
  const getAgent = () => currentAgent ?? ctx.agents.list()[0]

  // 初始化三个模块
  const toolMod = createToolModule(ctx, getAgent)
  const mcpMod = createMcpModule(ctx, getAgent)
  const skillMod = createSkillModule(ctx, getAgent)

  // 注册 HTTP API
  registerApi(ctx, { toolMod, mcpMod, skillMod, getAgent })

  // 注入前端 widget
  ctx.on('webserver/index-inject', (table) => {
    table.push({ kind: 'script-src', placement: 'body', src: '/api/tohelper/widget.js' })
  })
  ctx.webServer.register({
    kind: 'exact',
    path: '/api/tohelper/widget.js',
    handler(_req, res) {
      res.writeHead(200, { 'Content-Type': 'application/javascript; charset=utf-8' })
      res.end(getWidgetScript())
    },
  })
}
```

## HTTP API 设计 (`src/api.ts`)

| Method | Path | 说明 | 模块 |
|--------|------|------|------|
| GET | `/api/tohelper/tools` | 获取分类后的工具列表 | tool |
| GET | `/api/tohelper/skills` | 获取技能目录 | skill |
| GET | `/api/tohelper/mcp/servers` | 列出动态添加的 MCP 服务器 | mcp |
| POST | `/api/tohelper/mcp/add` | 添加 MCP 服务器 | mcp |
| POST | `/api/tohelper/mcp/remove` | 移除 MCP 服务器 | mcp |
| POST | `/api/tohelper/mcp/deny` | 禁用指定 MCP 工具 | mcp |
| POST | `/api/tohelper/mcp/reset` | 恢复全部 MCP 工具 | mcp |
| GET | `/api/tohelper/status` | 插件整体状态概览 | - |

## 挂载方式（零侵入）

### 开发时

创建 `cordis.patch.yml`：

```yaml
- insert:
    - id: tohelper
      name: 'file:///E:/codes/claude/ID/mcp-plugin/codes/tohelper/src/index.ts'
```

启动命令：
```bash
pnpm dsh web --patch "E:/codes/claude/ID/mcp-plugin/codes/tohelper/cordis.patch.yml"
```

插件作为 **host 层行** 加载（与 webserver、agent-presets 同级），通过 inject `agents` 和事件监听获取 agent scope。

### 发布时

三种分发方式：
1. **Profile patch**：用户在自己 profile 的 `cordis.patch.yml` 中引入
2. **Bundle**：打包为 `@xxx/dsh-tohelper` bundle，通过 `dsh.bundle.patch` 声明
3. **Out-of-tree plugin**：`pnpm add` 安装到 profile 目录，patch 里引用包名

以上三种都不需要修改 DSH 源码。

## 与 DSH 的接口边界

```
                    DSH 进程
┌──────────────────────────────────────────────────┐
│                                                  │
│  ┌── Host 层 ──────────────────────────────────┐ │
│  │                                              │ │
│  │  webServer (Service)  ◄─── tohelper 注册路由 │ │
│  │  agents   (Service)   ◄─── tohelper 监听事件 │ │
│  │  tools    (Service)   ◄─── tohelper 读/restrict │
│  │  skills   (Service)   ◄─── tohelper 读 list  │ │
│  │                                              │ │
│  │  webserver/index-inject ◄── tohelper 注入 JS │ │
│  │                                              │ │
│  └──────────────────────────────────────────────┘ │
│                                                  │
│  ┌── Agent Scope (per session) ────────────────┐ │
│  │                                              │ │
│  │  tool-bash, tool-fs, tool-skill...          │ │
│  │  mcp-client instances (动态加载的也在这)     │ │
│  │                                              │ │
│  └──────────────────────────────────────────────┘ │
│                                                  │
└──────────────────────────────────────────────────┘

tohelper 只通过公开 Service API 和事件交互，不修改任何 DSH 源码。
```

**消费的 DSH 公开接口**：

| 接口 | 来源包 | 用途 |
|------|--------|------|
| `ctx.webServer.register()` | `dsh-host-webserver` | 注册 HTTP 路由 |
| `ctx.on('webserver/index-inject')` | `dsh-host-webserver` | 注入前端脚本 |
| `ctx.agents.list()` | `dsh-agent` | 获取活跃 agent |
| `ctx.on('agent/created')` | `dsh-agent` | 监听 agent 创建 |
| `ctx.on('agent/disposed')` | `dsh-agent` | 监听 agent 销毁 |
| `ctx.tools.schemas(scope)` | `dsh-tools` | 读取 scoped 工具列表 |
| `agent.ctx.tools.restrict()` | `dsh-tools` | 对 agent 执行 restrict |
| `ctx.skills.list(options)` | `dsh-skill` | 读取 scoped 技能列表 |
| `ctx.plugin(module, config)` | `cordis` | 动态加载 MCP client |
