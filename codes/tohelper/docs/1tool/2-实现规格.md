# Phase 1 实现规格

## 文件详细设计

### src/index.ts — 主入口

```ts
import type { Context } from '@deepseek-ai/cordis'

export const name = 'tohelper'
export const inject = ['commands', 'tools'] as const

export function apply(ctx: Context): void {
  // 1. 注册 /tools 命令
  // 2. 注册 /equip 命令
  // 3. 注册 /unequip 命令
}
```

**职责**：
- 声明依赖：`commands`（注册命令）+ `tools`（发现和限制工具）
- 注册三个命令，每个命令的 handler 分别调用 discovery / assembly 模块
- 不持有全局状态（状态在 assembly.ts 中按 agent 隔离）

### src/discovery.ts — 工具发现

```ts
import type { Context } from '@deepseek-ai/cordis'

export interface ToolInfo {
  name: string
  description: string
  source: 'builtin' | 'mcp'
  mcpServer?: string    // MCP 工具时的 server 名称
}

/**
 * 列出全局注册的所有工具（不受任何 restrict 影响）。
 */
export function listAllTools(ctx: Context): ToolInfo[]

/**
 * 按关键词过滤工具列表。
 * 匹配 name 或 description（大小写不敏感）。
 */
export function searchTools(ctx: Context, keyword: string): ToolInfo[]

/**
 * 检查指定工具名是否存在于全局注册表。
 */
export function toolExists(ctx: Context, name: string): boolean

/**
 * 给一个不存在的名称，找出最接近的已有工具名（用于错误提示）。
 */
export function suggestSimilar(ctx: Context, name: string, limit?: number): string[]
```

**实现要点**：
- `ctx.tools.schemas()` 不传 scope → 返回全局全量 schema
- MCP 判断：`name.startsWith('mcp__')` → 解析 `mcp__<serverName>__<rawName>`
- 模糊搜索用 `includes()` 即可（Phase 1 不需要 fuzzy match 库）
- `suggestSimilar` 用 Levenshtein 距离或简单 prefix match

### src/assembly.ts — 装配状态管理

```ts
import type { Context } from '@deepseek-ai/cordis'

export interface AssemblyState {
  equipped: Set<string>
  restrictDisposer: (() => void) | undefined
}

/**
 * 获取或创建 agent 的装配状态。
 */
export function getState(agent: Agent): AssemblyState

/**
 * 装配工具（追加模式）。
 * 返回实际新增的工具名列表。
 */
export function equipTools(
  ctx: Context,
  agent: Agent,
  names: string[],
): { added: string[]; alreadyEquipped: string[]; notFound: string[] }

/**
 * 精确设定装配（替换模式）。
 */
export function equipOnly(
  ctx: Context,
  agent: Agent,
  names: string[],
): { equipped: string[]; notFound: string[] }

/**
 * 卸载指定工具。
 */
export function unequipTools(
  ctx: Context,
  agent: Agent,
  names: string[],
): { removed: string[]; notEquipped: string[] }

/**
 * 移除全部限制，恢复默认全部可见。
 */
export function unequipAll(agent: Agent): void

/**
 * 获取当前已装配的工具名集合（用于 /tools 显示状态）。
 * 返回 undefined 表示"未启用装配"（全部可见）。
 */
export function getEquipped(agent: Agent): Set<string> | undefined
```

**实现要点**：
- 使用 `WeakMap<Agent, AssemblyState>` 隔离状态
- 每次 equip/unequip 都要：先 dispose 旧 restriction → 计算新 allow 集合 → 调用 `agent.ctx.tools.restrict()`
- `equipOnly` 是替换语义：丢弃旧集合，设置为新列表
- `unequipAll` 只需 dispose restrictDisposer 并清空 Set

### src/types.ts — 类型定义

```ts
/** 命令解析结果 */
export interface EquipArgs {
  mode: 'append' | 'only' | 'all'
  names: string[]
}

export interface UnequipArgs {
  mode: 'specific' | 'all'
  names: string[]
}

export interface ToolsFilterArgs {
  filter: 'all' | 'equipped' | 'mcp'
  keyword?: string
}
```

## 命令参数解析规则

### /equip 解析

```
/equip read_file write       → { mode: 'append', names: ['read_file', 'write'] }
/equip --only read_file      → { mode: 'only', names: ['read_file'] }
/equip --all                 → { mode: 'all', names: [] }
```

### /unequip 解析

```
/unequip grep read_file      → { mode: 'specific', names: ['grep', 'read_file'] }
/unequip --all               → { mode: 'all', names: [] }
```

### /tools 解析

```
/tools                       → { filter: 'all' }
/tools --equipped            → { filter: 'equipped' }
/tools --mcp                 → { filter: 'mcp' }
/tools search_term           → { filter: 'all', keyword: 'search_term' }
```
