## 📝 配置文件格式

### Direct 模式 Node
```json
{
  "id": "node-xxx",
  "name": "text_summarizer",
  "description": "Summarize text",
  "executionMode": "direct",
  "systemPrompt": "You are a summarizer...",
  "llm": {
    "provider": "deepseek-official",
    "model": "deepseek-chat",
    "temperature": 0.7
  },
  "tools": [],
  "inputSchema": { "type": "object", "properties": {} },
  "outputSchema": { "type": "object", "properties": {} },
  "createdAt": "2026-08-30T07:00:00Z"
}
```

### Pipeline 模式 Node
```json
{
  "id": "node-yyy",
  "name": "code_analyzer",
  "description": "Analyze code",
  "executionMode": "pipeline",
  "tasks": [
    {
      "id": "task-1",
      "name": "Read File",
      "type": "tool-call",
      "config": {
        "toolName": "read_file"
      }
    },
    {
      "id": "task-2",
      "name": "Analyze",
      "type": "llm-call",
      "config": {
        "systemPrompt": "Analyze code...",
        "outputFormat": "text"
      }
    }
  ],
  "tools": ["read_file"],
  "inputSchema": { "type": "object", "properties": {} },
  "outputSchema": { "type": "object", "properties": {} },
  "createdAt": "2026-08-30T07:00:00Z"
}
```
