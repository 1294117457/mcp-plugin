## 测试场景 1: 创建 Simple Node (Direct 模式)

### 步骤
1. 点击右下角悬浮按钮
2. 选择"节点"
3. 点击"+ 创建节点"
4. 填写：
   - **节点名称**: `text_summarizer`
   - **节点描述**: `Summarize text in 3 sentences`
   - **执行模式**: 选择 `Direct`
5. 在 Direct 配置中填写：
   - **System Prompt**: `You are a professional summarizer. Summarize the user's input in exactly 3 sentences.`
   - **LLM 模型**: `deepseek-chat`
   - **Temperature**: `0.5`
6. 点击"保存"
7. 在节点列表中，点击"装配"按钮

### 验证
- 在对话框中输入：
  ```
  帮我用 text_summarizer 总结这段文字：
  
  人工智能技术近年来发展迅速，特别是大型语言模型的出现，改变了人机交互的方式。这些模型能够理解和生成自然语言，应用范围从聊天机器人到代码生成，再到内容创作。随着技术的进步，AI 的能力不断增强，但同时也带来了伦理和安全方面的挑战。如何确保 AI 的发展造福人类，是当前研究者和政策制定者面临的重要课题。
  ```

**期望结果**：返回 3 句话的总结

## 测试场景 2: 创建 Complex Node (Pipeline 模式)

### 步骤
1. 点击右下角悬浮按钮
2. 选择"节点"
3. 点击"+ 创建节点"
4. 填写基础信息：
   - **节点名称**: `file_analyzer`
   - **节点描述**: `Analyze a file and provide insights`
   - **执行模式**: 选择 `Pipeline`
5. 添加 Task 1：
   - 点击"+ 添加 Task"
   - 展开 Task（点击 Task 卡片）
   - **Task 名称**: `Read File`
   - **Task 类型**: `Tool Call`
   - **选择 Tool**: `read_file`（如果没有，需要先在工具面板中添加）
6. 添加 Task 2：
   - 点击"+ 添加 Task"
   - 展开 Task
   - **Task 名称**: `Analyze Content`
   - **Task 类型**: `LLM Call`
   - **System Prompt**: `You are a code analyst. Analyze the provided file content and give insights about: 1) Purpose, 2) Key components, 3) Potential improvements.`
7. 在"允许的工具"中勾选相关工具（如果有）
8. 点击"保存"
9. 在节点列表中，点击"装配"按钮

### 验证
- 在对话框中输入：
  ```
  帮我用 file_analyzer 分析 /home/dustp/codes/mcp-plugin/codes/tohelper/README.md
  ```

**期望结果**：
1. Task 1 读取文件内容
2. Task 2 分析文件内容
3. 返回分析结果

## 常见问题

### Q1: 点击悬浮按钮没有反应
**解决**：刷新页面，确保插件已加载

### Q2: 找不到"节点"选项
**解决**：检查 `src/client/home/index.tsx` 中的 SatelliteMenu 配置

### Q3: 保存 Node 时报错
**解决**：
1. 检查控制台错误信息
2. 确保节点名称符合规则（小写字母、数字、下划线，3-50字符）
3. 确保必填字段都已填写

### Q4: Tool Call Task 找不到工具
**解决**：
1. 在"工具"面板中先添加 MCP 服务器或查看内置工具
2. 在 Node 的"允许的工具"中勾选对应工具

### Q5: Pipeline 执行失败
**解决**：
1. 查看错误信息中的 Execution log
2. 检查每个 Task 的配置是否正确
3. 确保 Task 间的数据传递格式匹配
