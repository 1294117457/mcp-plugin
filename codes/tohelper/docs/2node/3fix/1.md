### 3. 三种 Mode 详解

#### Direct 模式（单个任务）

场景：简单任务，只需要一个 Task

Node (node_prompt: "查询天气")

└── Task (task_prompt: "查询北京天气", tools: ["weather-api"])

执行流程：

1. 执行第一个 Task
2. 返回结果

实现：

async runDirect(node, input) {

  const task = node.tasks[0]

  return this.runTask(task, node, input)

}

#### Pipeline 模式（线性顺序）

场景：多步骤流程，前一步输出作为后一步输入

Node (node_prompt: "查询并整合优惠")

├── Task 1 (查询瑞幸门店, tools: ["coffee-api"])

├── Task 2 (查询麦当劳优惠, tools: ["mcd-api"])

└── Task 3 (整合结果, tools: [])

执行流程：

Task 1 输出 → Task 2 输入 → Task 3 输入 → 最终结果

实现：

async runPipeline(node, input) {

  let result = input

  for (const task of node.tasks) {

​    result = await this.runTask(task, node, result)

  }

  return result

}

#### Loop 模式（LLM 动态调度）⭐

场景：复杂任务，Task 执行顺序不确定

Node (node_prompt: "完成数据分析")

├── Task 1 (数据清洗, tools: ["clean-tool"])

├── Task 2 (数据可视化, tools: ["chart-tool"])

├── Task 3 (生成报告, tools: ["report-tool"])

└── Task 4 (数据统计, tools: ["stats-tool"])

执行流程：

1. Node LLM 分析 nodePrompt
2. 决定执行顺序：[4, 1, 2, 3]
3. 动态选择需要的 Tasks
4. 循环执行直到任务完成

实现：

async runLoop(node, input) {

  let context = { input, history: [], completed: [] }

  

  while (context.history.length < node.tasks.length) {

​    *// LLM 决定下一步*

​    const decision = await node.llm.decide({

​      nodePrompt: node.nodePrompt,

​      availableTasks: node.tasks,

​      context

​    })

​    

​    if (decision.action === 'done') {

​      return decision.result

​    }

​    

​    *// 执行选定的 Task*

​    const task = node.tasks.find(t => t.id === decision.taskId)

​    const result = await this.runTask(task, node, context.input)

​    

​    context.history.push({ taskId: task.id, result })

​    context.input = result

  }

  

  return context.input

}

### 5. 技术实现方案

#### 执行器架构

class NodeExecutor {

  async run(node: NodeConfig, input: unknown): Promise<unknown> {

​    const llm = this.prepareLLM(node.llm)

​    

​    switch (node.mode) {

​      case 'direct':

​        return this.runDirect(node, llm, input)

​      case 'pipeline':

​        return this.runPipeline(node, llm, input)

​      case 'loop':

​        return this.runLoop(node, llm, input)

​    }

  }

  

  async runTask(task: TaskConfig, node: NodeConfig, input: unknown) {

​    const taskLLM = task.llm || node.llm

​    const tools = task.tools.length > 0 ? task.tools : node.tools

​    

​    *// 调用 LLM*

​    const result = await llm.execute({

​      prompt: task.taskPrompt,

​      tools,

​      model: taskLLM.model,

​      provider: taskLLM.provider,

​      input

​    })

​    

​    return result

  }

}
