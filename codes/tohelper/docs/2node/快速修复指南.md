# 快速修复指南：Pipeline 模式 LLM 配置错误

## ❌ 错误现象

```
Error: LLM call failed: prepared LLM call config changed before adapter dispatch
```

## 🔍 问题原因

Pipeline 模式的 Node 缺少 LLM 配置，导致 `llm-call` Task 执行失败。

## ✅ 快速修复（3 种方法）

### 方法 1：通过 UI（推荐）⭐

1. 打开节点面板
2. 点击现有 Node 的"编辑"按钮
3. 找到"**LLM 配置**"区域（新增的独立 Section）
4. 选择模型：`deepseek-official/deepseek-chat`
5. 设置 Temperature：`0.7`
6. 点击"**保存**"
7. 如果 Node 已装配，先"**卸载**"再"**装配**"

### 方法 2：通过 API

```bash
# 1. 查看现有配置
curl http://localhost:3000/api/tohelper/node/list | jq '.nodes[] | {id, name, llm}'

# 2. 更新配置（替换 YOUR_NODE_ID）
curl -X POST http://localhost:3000/api/tohelper/node/update \
  -H "Content-Type: application/json" \
  -d '{
    "id": "YOUR_NODE_ID",
    "name": "your_node_name",
    "description": "your description",
    "executionMode": "pipeline",
    "llm": {
      "provider": "deepseek-official",
      "model": "deepseek-chat",
      "temperature": 0.7,
      "maxTokens": 2000
    },
    "tasks": [...],
    "tools": [...]
  }'

# 3. 重新装配
curl -X POST http://localhost:3000/api/tohelper/node/unequip \
  -H "Content-Type: application/json" \
  -d '{"id": "YOUR_NODE_ID"}'

curl -X POST http://localhost:3000/api/tohelper/node/equip \
  -H "Content-Type: application/json" \
  -d '{"id": "YOUR_NODE_ID"}'
```

### 方法 3：直接编辑配置文件

```bash
# 1. 编辑配置文件
vim /home/dustp/codes/mcp-plugin/codes/tohelper/data/node-config.json

# 2. 在每个 Pipeline Node 中添加 llm 字段
{
  "nodes": {
    "node-xxx": {
      "name": "your_node",
      "executionMode": "pipeline",
      "llm": {                    // ← 添加这个
        "provider": "deepseek-official",
        "model": "deepseek-chat",
        "temperature": 0.7,
        "maxTokens": 2000
      },
      "tasks": [...],
      "tools": [...]
    }
  }
}

# 3. 重启 dsh
```
