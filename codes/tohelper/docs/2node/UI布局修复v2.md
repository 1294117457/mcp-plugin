## 🎯 使用指南

### 添加自定义 LLM 给 Task
1. 点击 Task 展开详细内容
2. 找到"🤖 LLM 模型配置"区域（蓝色背景）
3. 勾选"自定义"复选框
4. 从下拉框选择模型
5. 状态提示变为"✅ 此 Task 使用独立的 LLM 配置"

### 多选 Tools
1. 按住 **Ctrl** (Windows/Linux) 或 **Cmd** (Mac)
2. 点击多个工具名称
3. 选中的工具会高亮显示

### 切换 Mode
1. 点击 **Direct** / **Pipeline** / **Loop** 按钮
2. 按钮会变为蓝色激活状态
3. 下方显示对应的模式说明
