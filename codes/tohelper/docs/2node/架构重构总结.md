## 🎯 新架构核心优势

### 1. 概念简化
- **Task** = LLM + Tools + Prompt
- **Node** = LLM + Tasks + Mode + Prompt
- 移除复杂的 type 和 config 嵌套

### 2. 灵活配置
- Task 可配置多个 tools
- Task 可独立配置 LLM
- Node 和 Task 都有明确的 prompt

### 3. 强大编排
- **Direct**：单任务
- **Pipeline**：顺序执行
- **Loop**：智能调度（核心创新）

### 4. 易于理解
- `nodePrompt`：整体目标
- `taskPrompt`：具体任务
- `mode`：执行方式

### 5. 向后兼容
- 保留旧类型（deprecated）
- 提供迁移工具
- 支持新旧编辑器

## 📊 对比表

| 特性 | 旧架构 | 新架构 |
|------|--------|--------|
| Task 类型 | type + config | 统一 |
| Task 工具 | 单个 toolName | 多个 tools[] |
| Task Prompt | systemPrompt | taskPrompt |
| Node Prompt | systemPrompt (direct) | nodePrompt (统一) |
| 执行模式 | executionMode | mode |
| Mode 选项 | direct, pipeline | direct, pipeline, loop |
| LLM 配置 | 可选 | Node 必需，Task 可选 |

## 🚀 使用指南

### 1. 创建 Pipeline Node

```typescript
{
  nodePrompt: "查询并整合优惠信息",
  mode: "pipeline",
  tasks: [
    { taskPrompt: "查询数据", tools: ["query-tool"] },
    { taskPrompt: "处理数据", tools: ["process-tool"] },
    { taskPrompt: "展示结果", tools: [] }
  ]
}
```

**执行流程**：Task 1 → Task 2 → Task 3

### 2. 创建 Loop Node

```typescript
{
  nodePrompt: "完成数据分析任务",
  mode: "loop",
  tasks: [
    { taskPrompt: "数据清洗", tools: ["cleaner"] },
    { taskPrompt: "统计分析", tools: ["stats"] },
    { taskPrompt: "可视化", tools: ["chart"] },
    { taskPrompt: "生成报告", tools: ["writer"] }
  ]
}
```

**执行流程**：LLM 动态决定执行顺序，例如：
1. LLM 分析：需要先清洗数据
2. 执行 Task 1（数据清洗）
3. LLM 分析：现在可以统计分析
4. 执行 Task 2（统计分析）
5. LLM 分析：生成可视化
6. 执行 Task 3（可视化）
7. LLM 分析：最后生成报告
8. 执行 Task 4（生成报告）
9. 完成

### 3. Task 级别 LLM 配置

```typescript
{
  nodePrompt: "多模型协作任务",
  mode: "pipeline",
  llm: { provider: "deepseek-official", model: "deepseek-chat" },
  tasks: [
    {
      taskPrompt: "代码生成",
      tools: ["code-tool"],
      llm: { provider: "deepseek-official", model: "deepseek-coder" }
    },
    {
      taskPrompt: "深度推理",
      tools: [],
      llm: { provider: "deepseek-official", model: "deepseek-reasoner" }
    },
    {
      taskPrompt: "结果总结",
      tools: []
      // 继承 Node 的 deepseek-chat
    }
  ]
}
```
