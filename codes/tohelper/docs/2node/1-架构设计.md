## Host 侧架构

### 组合入口

```typescript
// src/host/index.ts
export const name = 'tohelper'
export const inject = ['webServer', 'tools', 'llm'] as const

export function apply(ctx: Context): void {
  const tracker = createAgentTracker(ctx)
  setupToolModule(ctx, tracker)
  setupNodeModule(ctx, tracker)
}
```

`inject` 新增 `'llm'` — Node 执行需要调用 LLM。暂不引入 `'agents'`（Phase 1 用 direct 模式，不创建子 agent）。

### Agent Tracker（共享）

从现有 `index.ts` 中提取 agent 追踪逻辑：

```typescript
// src/host/agent-tracker.ts
export interface AgentTracker {
  getAgent(): any | undefined
}

export function createAgentTracker(ctx: Context): AgentTracker {
  let currentAgent: any
  ctx.on('agent/created', ({ agent }) => { currentAgent = agent })
  ctx.on('agent/disposed', ({ agent }) => {
    if (currentAgent === agent) currentAgent = undefined
  })
  return {
    getAgent() {
      if (currentAgent) return currentAgent
      // fallback
      const agents = (ctx as any).agents
      if (agents?.list) return agents.list()[0]
      return undefined
    },
  }
}
```


## 数据流

### Node 定义（在 Node 面板）

```
Client (NodeEditor)
  │ POST /api/tohelper/node/create { name, description, ... }
  ▼
Host (node/routes.ts)
  │ 校验 → 写入内存 + 持久化
  ▼
data/node-config.json 更新
  ▼
Tool 面板刷新时，node tools 分组出现新条目
```

### Node 装配（在 Tool 面板）

```
Client (ToolPanel → Node Tools 分组)
  │ POST /api/tohelper/node/equip { nodeId }
  ▼
Host (node/index.ts)
  │ 1. 读取 NodeConfig
  │ 2. 构造 ToolDefinition
  │ 3. agent.ctx.tools.register(toolDef) → 获得 disposer
  │ 4. 记录 equipped 状态
  ▼
Agent 的 tool schemas 中出现该 Node tool
  ▼
Tool 面板中该 node 显示"已装配"状态
```

### Node 执行（在对话中）

```
用户对话："用 code_reviewer 审查 src/index.ts"
  │
  ▼
Agent loop → tool call: code_reviewer({ file_path: "src/index.ts" })
  │
  ▼
Node tool execute(args):
  │ 1. 组装 messages（system prompt + 用户输入）
  │ 2. ctx.llm.prepareCall(nodeConfig.llm)
  │ 3. preparedCall.stream(request)
  │ 4. 收集响应 → 返回结果
  ▼
结果回到主对话 → agent 继续
```

### 统一装配模型

```
               Tool 面板（统一视图）
┌──────────────────────────────────────────────────┐
│  [Builtin]  read_file ✓  write ✓  grep ✗        │ ← restrict({ deny })
│  [MCP]      mcp__gh__search ✓  mcp__gh__pr ✗    │ ← restrict({ deny })
│  [Skill]    skill_docker ✓                       │ ← 只读展示
│  [Node]     code_reviewer ✓  translator ✗       │ ← register/dispose
│  [Workflow] deploy_pipeline ✗                    │ ← (Phase 3)
└──────────────────────────────────────────────────┘
```

不同来源的 tool 装配机制不同：
- Builtin / MCP：通过 `tools.restrict({ deny })` 控制可见性（隐藏 = deny）
- Node / Workflow：通过 `tools.register()` / `dispose()` 控制存在性（装配 = 注册）
