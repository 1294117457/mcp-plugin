### 2. 修复 Pipeline 模式 LLM 配置问题

#### 问题分析
```
Error: LLM call failed: prepared LLM call config changed before adapter dispatch
```

**根本原因**：
- Pipeline 模式的 Node 没有配置 LLM
- llm-call Task 依赖 Node 级别的 LLM 配置
- 回退到 `getDefaultLLM()` 时配置不稳定

#### 解决方案
1. **强制所有 Node 配置 LLM**
   - Direct 模式：保存时包含 LLM 配置
   - Pipeline 模式：保存时包含 LLM 配置
   - llm-call Task 继承 Node 级别配置

2. **优先级机制**
   ```
   Task 级 llm > Node 级 llm > 默认 llm
   ```

3. **UI 调整**
   - LLM 配置从 Direct Section 提取到独立 Section
   - 所有执行模式都显示 LLM 配置
