# 新架构快速上手指南

## 🚀 5 分钟上手

### 核心概念

```
Task = LLM + Tools + Prompt（执行单元）
Node = LLM + Tasks + Mode + Prompt（任务编排）
```

### 三种 Mode

| Mode | 说明 | 适用场景 |
|------|------|---------|
| **Direct** | 执行单个 Task | 简单任务 |
| **Pipeline** | 顺序执行多个 Tasks | 多步骤流程 |
| **Loop** | LLM 动态调度 Tasks | 复杂任务 |

---

## 📝 示例 1: Pipeline Node

### 场景：查询附近优惠

**Node Prompt**：
```
查询附近的瑞幸咖啡门店和麦当劳优惠券，并整合展示
```

**Mode**：`pipeline`

**Tasks**：

1. **查询瑞幸门店**
   - Task Prompt：`查询用户附近的瑞幸咖啡门店`
   - Tools：`mcp__my-coffee__queryShopList`
   
2. **查询麦当劳优惠**
   - Task Prompt：`查询麦当劳可领取的优惠券`
   - Tools：`mcp__mcd-mcp__available-coupons`
   
3. **整合结果**
   - Task Prompt：`整合查询结果，用友好方式展示`
   - Tools：（无）

**执行流程**：Task 1 → Task 2 → Task 3

## 📝 示例 2: Loop Node

### 场景：数据分析

**Node Prompt**：
```
分析销售数据并生成完整报告
```

**Mode**：`loop`

**Tasks**：

1. **数据清洗**
   - Task Prompt：`清洗异常数据和缺失值`
   - Tools：`cleaner`, `validator`
   
2. **统计分析**
   - Task Prompt：`计算关键统计指标`
   - Tools：`stats-calculator`
   
3. **数据可视化**
   - Task Prompt：`生成可视化图表`
   - Tools：`chart-generator`
   
4. **报告生成**
   - Task Prompt：`整合分析结果生成报告`
   - Tools：`report-writer`

**执行流程**：LLM 决定执行顺序（例如：1 → 2 → 3 → 4）

## 🎨 UI 操作指南

### 创建新 Node

1. **打开节点面板**
   - 点击浮动按钮

2. **创建节点**
   - 点击"创建新节点"

3. **填写基础信息**
   ```
   节点名称：query_nearby_deals
   节点描述：查询附近商家优惠
   Node Prompt：查询附近的瑞幸咖啡门店和麦当劳优惠券
   ```

4. **选择 Mode**
   - ○ Direct
   - ● Pipeline ← 选择
   - ○ Loop

5. **配置 LLM**
   ```
   模型：deepseek-official/deepseek-chat
   Temperature：0.7
   ```

6. **添加 Tasks**
   - 点击"+ 添加 Task"
   - 配置每个 Task

### 配置 Task

1. **展开 Task**
   - 点击 Task 卡片

2. **填写信息**
   ```
   Task 名称：查询瑞幸门店
   Task Prompt：查询用户附近的瑞幸咖啡门店
   ```

3. **选择 Tools**
   ```
   ☑ mcp__my-coffee__queryShopList
   ☐ mcp__mcd-mcp__available-coupons
   ```

4. **配置 LLM（可选）**
   ```
   ○ 继承 Node 配置
   ● 自定义配置
     deepseek-official/deepseek-coder
   ```

5. **输出格式**
   ```
   json ▼
   ```

## 🔧 配置技巧

### 1. 何时使用 Direct 模式？

**适合**：
- 单个工具调用
- 简单查询
- 快速响应

**示例**：
```
Node Prompt：查询天气
Tasks：
  - Task Prompt：查询北京天气
    Tools：weather-api
```

### 2. 何时使用 Pipeline 模式？

**适合**：
- 多步骤流程
- 数据流转
- 顺序依赖

**示例**：
```
Node Prompt：数据处理流程
Tasks：
  1. 加载数据
  2. 清洗数据
  3. 分析数据
  4. 生成报告
```

### 3. 何时使用 Loop 模式？

**适合**：
- 复杂任务
- 执行顺序不确定
- 需要智能决策

**示例**：
```
Node Prompt：智能数据分析
Tasks：
  - 数据加载
  - 数据清洗
  - 统计分析
  - 可视化
  - 报告生成

（LLM 会根据数据情况动态决定执行顺序）
```

### 4. 何时配置 Task 独立 LLM？

**适合**：
- 代码生成（使用 deepseek-coder）
- 深度推理（使用 deepseek-reasoner）
- 特定任务需要特定模型

**示例**：
```
Task 1: 代码生成
  LLM：deepseek-coder
  
Task 2: 代码分析
  LLM：deepseek-reasoner
  
Task 3: 结果总结
  LLM：继承 Node（deepseek-chat）
```

### 5. 如何选择 Tools？

**单工具**：
```
Tools：[weather-api]
适用：明确的单一工具调用
```

**多工具**：
```
Tools：[cleaner, validator, formatter]
适用：需要多个工具协作
```

**无工具**：
```
Tools：[]
适用：纯 LLM 处理（总结、分析、转换）
```

## 🐛 常见问题

### Q1: Task Prompt 和 Node Prompt 有什么区别？

**A**：
- **Node Prompt**：描述整个 Node 要完成的**任务目标**
- **Task Prompt**：描述单个 Task 要完成的**具体任务**

**示例**：
```
Node Prompt：查询并整合优惠信息（整体目标）
  Task 1 Prompt：查询瑞幸门店（具体任务）
  Task 2 Prompt：查询麦当劳优惠（具体任务）
  Task 3 Prompt：整合结果（具体任务）
```

### Q2: Loop 模式如何工作？

**A**：
1. LLM 分析 Node Prompt（任务目标）
2. 查看可用的 Tasks
3. 决定下一步执行哪个 Task
4. 执行 Task
5. 根据结果决定是否继续或完成

### Q3: 如何判断任务应该用 Pipeline 还是 Loop？

**A**：
- **Pipeline**：任务步骤明确，有固定顺序
- **Loop**：任务步骤不确定，需要动态决策

**示例**：
```
Pipeline：查询数据 → 处理数据 → 展示结果（固定顺序）
Loop：分析数据（可能需要清洗 → 分析 → 可视化，或者清洗 → 可视化 → 分析）
```

### Q4: Task 不配置 Tools 会怎样？

**A**：
- Task 会使用 Node 级别的 Tools
- 如果 Node 也没有配置 Tools，则纯 LLM 处理

### Q5: Task 不配置 LLM 会怎样？

**A**：
- Task 会继承 Node 级别的 LLM 配置
