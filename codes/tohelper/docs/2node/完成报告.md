## 🎯 核心特性

### 简化的架构

**旧架构**:
```typescript
Task {
  type: 'llm-call' | 'tool-call' | 'transform'
  config: { systemPrompt?, toolName?, ... }
}
```

**新架构**:
```typescript
Task {
  taskPrompt: string
  tools: string[]
  llm?: LLMSlot
}
```

### 三种执行模式

| Mode | 说明 | 适用场景 |
|------|------|---------|
| **Direct** | 执行单个 Task | 简单任务 |
| **Pipeline** | 顺序执行多个 Tasks | 多步骤流程 |
| **Loop** | LLM 动态调度 Tasks | 复杂任务 |

### 灵活的配置

- ✅ Task 可配置多个 tools
- ✅ Task 可独立配置 LLM
- ✅ Node 和 Task 都有明确的 prompt
- ✅ 优先级：`Task.llm > Node.llm`
