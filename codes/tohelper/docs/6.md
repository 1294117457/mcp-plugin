## DSH 中工具的三类来源

### 1. 内置 tools（built-in）

在 `standard` 预设中注册的工具：

| 工具                         | 插件                                   |
| :--------------------------- | :------------------------------------- |
| `bash` / `pwsh`              | `dsh-tool-bash` / `dsh-tool-pwsh`      |
| `read` / `write` / `edit`    | `dsh-tool-fs`                          |
| `glob` / `grep`              | `dsh-tool-fs-search`                   |
| `str_replace_editor`         | `dsh-tool-str-replace-editor`          |
| `skill`                      | `dsh-tool-skill`                       |
| `todo_write`                 | `dsh-tool-todo`                        |
| `subagent` / `subagent_fork` | `dsh-tool-subagent`                    |
| `ask_user_question`          | `dsh-tool-ask-user`                    |
| `web_search`                 | `dsh-tool-web`                         |
| `goal`                       | `dsh-tool-goal`                        |
| `job_status` / `job_stop`    | `dsh-tool-jobs`                        |
| `workflow` / `ralph`         | `dsh-tool-workflow` / `dsh-tool-ralph` |

这些是 agent 的基础能力，一般不应该被用户随意摘掉。

### 2. MCP tools（外部接入）

通过 `@deepseek-ai/dsh-mcp-client` 接入，命名格式固定：`mcp__<serverName>__<toolName>`。例如接入一个 Engram 记忆服务器：

\- id: memory-engram

  name: '@deepseek-ai/dsh-mcp-client'

  config:

​    serverName: engram

​    transport: stdio

​    command: engram

​    args: [mcp]

​    cwd: !!js process.cwd()

MCP 工具的特点是：动态、来自外部进程、可能很多、质量参差不齐——正是需要"选择性装配"的目标。

### 3. Skills（技能）

Skill 不是 tool。`skill` 本身是一个 tool，用来按名加载技能文档。技能是"按需加载的知识"而非"可调用的工具"。模型决定何时加载哪个 skill。

## 推荐的 tohelper 定位

┌────────────────────────────────────────────────────┐

│               tohelper 面板                          │

├────────────────────────────────────────────────────┤

│ 📋 内置工具 (read-only display, 总是活跃)           │

│   bash ✓  read ✓  write ✓  glob ✓  grep ✓  ...   │

│                                                    │

│ 🔌 MCP 工具 (可选择性启停)                          │

│   □ mcp__engram__store_memory                      │

│   ☑ mcp__engram__search_memory                     │

│   □ mcp__github__create_pr                         │

│   ...                                              │

│                                                    │

│ ➕ [添加 MCP 服务器]                                │

└────────────────────────────────────────────────────┘

核心逻辑：

1. 内置 tools：只展示，不能摘除（灰色/锁定状态）
2. MCP tools：可以通过 `ctx.tools.restrict()` 选择哪些对 agent 可见
3. MCP 服务器管理：可以动态添加新的 MCP server 连接

## 具体实现建议

### 插件位置：作为 preset 行

把 tohelper 加入 `standard/agent.cordis.yml`：

\- id: tohelper

  name: 'file:///E:/codes/claude/ID/mcp-plugin/codes/tohelper/src/index.ts'

这样它的 `ctx` 在 agent scope 内，`ctx.tools.schemas()` 能看到所有工具。

### 核心逻辑

export const inject = ['webServer', 'tools'] as const

export function apply(ctx: Context): void {

  *// 列出所有工具*

  *// schemas() 此时在 agent scope，能看到 bash/read/mcp__xxx 等全部*

  

  *// 分类*

  const allTools = ctx.tools.schemas()

  const builtins = allTools.filter(t => !t.name.startsWith('mcp__'))

  const mcpTools = allTools.filter(t => t.name.startsWith('mcp__'))

  

  *// restrict 只针对 MCP tools*

  *// 用户选择要禁用的 MCP 工具后：*

  ctx.tools.restrict({ deny: ['mcp__engram__store_memory'] })

}

### 动态添加 MCP 服务器

更高级的功能：通过 UI 让用户填写 MCP 服务器配置，然后在运行时动态 `plugin()` 一个 `mcp-client` 实例：

*// 动态加载一个 MCP server*

ctx.plugin(mcpClient, {

  serverName: 'my-server',

  transport: 'stdio',

  command: 'npx',

  args: ['-y', '@some/mcp-server'],

  cwd: process.cwd(),

  toolCallTimeoutMs: 60000,

  failOnStartupError: false,

})

注册后新工具会出现在 `ctx.tools.schemas()` 列表中（以 `mcp__my-server__*` 命名）。

## 总结

| 维度     | 内置 tools                  | MCP tools                  | Skills         |
| :------- | :-------------------------- | :------------------------- | :------------- |
| 可见性   | 只读展示                    | 可选择启停                 | 不属于 tool 层 |
| 操作     | 无                          | restrict/allow             | 无需管理       |
| 添加方式 | 预设自带                    | UI 配置 MCP server         | SKILL.md 文件  |
| 识别方式 | `!name.startsWith('mcp__')` | `name.startsWith('mcp__')` | -              |
